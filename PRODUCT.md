# Product
<!-- impeccable:product-schema 1 -->
## Platform
web
## Stack
User-specified React, Vite, Tailwind CSS, React Router, Lucide, Recharts; Python FastAPI, Uvicorn, SQLite, ThreadPoolExecutor. Requested GSAP plugins and Lenis.
## Users
Students presenting an academic PBL and faculty evaluating Computer Architecture and Parallel Processing.
## Product Purpose
Integrated Smart Healthcare Computing Solution: enter vitals, apply understandable educational rules, save results, simulate monitoring, and compare measured sequential and concurrent execution.
## Capabilities and Constraints
Five pages. No authentication, medical diagnosis, ML, hardware, or hospital management features. Demo-only controlled delays, exact measured timing, five independent tasks. Thread concurrency is not a claim of universal CPU parallelism. All sample and simulated data labeled.
## Brand Commitments
SmartHealth. The user's latest Observe reference supersedes the earlier porcelain design: dark liquid glass, monochrome controls, Instrument Serif headlines, full-screen slow video, and GSAP animation throughout all five pages. Smooth behavior and responsive layouts remain core requirements.
## Accessibility & Inclusion
Semantic controls, labeled inputs, text status indicators, reduced-motion support, mobile navigation, no horizontal page overflow from 320px.
## Evidence on Hand
Detailed user brief; synthetic sample vitals. No real patient or performance data preloaded.
